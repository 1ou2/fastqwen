# French and code prompt preparation

Prepared on November 3, 2026. No teacher containers were started and no answers
were generated during this preparation.

## Prepared artifacts

| Source | Directory | Generation prompts | Held-out prompts |
| --- | --- | ---: | ---: |
| CFP, French S1 | `data/runs/cfp-prep-20261103/` | 41,197 | 500 |
| Future Code, English S2 | `data/runs/future-code-prep-20261103/` | 50,000 | 500 |

Each directory contains `prompts.jsonl`, `heldout.jsonl`, `manifest.json`, and a
pinned `source-card.md`. These files are covered by the Spark backup script.
The manifests record source revisions, sampling settings, exclusion input
hashes, source distributions, output hashes, and rejection counts.

The original sources and supplied assistant answers are not training targets:
only the complete user prompt is exported for a fresh Qwen teacher answer.
Prepared records preserve source IDs or row positions and source metadata.
They are candidates for generation, not classifier-approved or QA-cleaned
teacher answers. No d1 suitability/routing pass was applied. In particular,
the old English regex filter must not be treated as a French classifier.

## Sources and selection

### CFP

[CATIE-AQ/CFP](https://huggingface.co/datasets/CATIE-AQ/CFP), revision
`8cc06909e4bd09255b3b379d9135f87fabeabc17`, is a semicolon-delimited `train.csv`.
Its actual columns are `inputs`, `targets`, `dataset`, `task`, and `subject`.
We preserve the complete `inputs` text, including embedded passages and choices;
`targets` is discarded. Subdataset, task, and subject are retained.

All 56,277 rows were scanned. Rejections were 8,369 benchmark-derived rows,
5,000 XGLUE/QAM rows with noncommercial/unclear terms, 312 upstream validation
rows, and 899 normalized duplicates. Of 41,697 eligible prompts, 500 were
reserved and 41,197 exported for generation. There were no over-limit inputs
or matches against the supplied previous English generation prompts.

Default source exclusions are:

- `facebook/belebele`: benchmark source.
- `Mathoctopus/GSM8KInstruct_Parallel`: benchmark source.
- `qanastek/frenchmedmcqa_validation`: upstream validation split.
- `xglue/qam`: noncommercial/unclear source terms.

This is a conservative filter, not a complete benchmark-contamination guarantee.
CFP is also not a balanced conversational sample: FAQ, movie, educational, and
structured tasks occupy substantial shares. Inspect its manifest distributions
before setting the final S1 mixture weights.

### Future Code

[future-architect/Llama-3.3-Future-Code-Instructions](https://huggingface.co/datasets/future-architect/Llama-3.3-Future-Code-Instructions),
revision `148be2ee007fcd511356e0a2a8212e7b6e0fda66`, contains 12 Parquet files
and over 11 million English/Japanese instructions.

Preparation streams only `id`, `input`, and `description_language`, with an
English predicate pushed into the Parquet reader. `output` is not projected.
The advertised `task_language` column is absent from some actual pinned shards;
it is not projected and is recorded as unknown rather than inferred.

Files are visited in seed-shuffled order. A deterministic reservoir selects
50,500 prompts from the first 250,000 English rows, then reserves 500 and exports
50,000. This is a bounded-prefix sample, not a uniform sample of all 6.1 million
English instructions. Every scanned English row was eligible in this run.
Do not assume it is balanced by programming language. To broaden coverage,
increase the scan budget or prepare another separately audited seed.

## Terms to review before training or publishing

CFP has **per-upstream licenses**, not one blanket license. Excluding XGLUE
does not remove attribution, share-alike, or other obligations of retained
sources. Read the saved card and the upstream terms; its medical-source
license descriptions are not entirely consistent. Regenerating answers does
not erase obligations associated with the input texts.

Future Code declares the **Llama 3.3 Community License**. Its instructions were
generated by Llama, so discarding its answers does not make it an Apache-licensed
source. Section 1.b.i of the
[Llama 3.3 agreement](https://github.com/meta-llama/llama-models/blob/main/models/llama3_3/LICENSE)
requires a `Llama` prefix for the name of a distributed or made-available AI
model trained or improved using Llama outputs. Review the full agreement,
including applicable attribution and acceptable-use obligations, before deciding
how to distribute the Qwen-based draft. Preparation is not legal clearance.

## Reproduce preparation

Run from the repository root with the main environment's dependencies installed.
Outputs must be fresh directories; existing directories are never overwritten.
Pinned source cards and the CFP CSV are downloaded through `huggingface_hub`;
Future Code is read with `datasets` streaming rather than downloaded in full.

```bash
source .venv/bin/activate

python -m scripts.prepare_generation_prompts \
  --source cfp \
  --out-dir data/runs/cfp-prep-new \
  --exclude-prompts data/runs/s1-night-20261101-222544/classification/S1.jsonl

python -m scripts.prepare_generation_prompts \
  --source future-code \
  --out-dir data/runs/future-code-prep-new \
  --count 50000 --scan-limit 250000 \
  --exclude-prompts data/runs/s1-night-20261101-222544/classification/S1.jsonl \
  --exclude-prompts data/runs/cfp-prep-new/prompts.jsonl \
  --exclude-prompts data/runs/cfp-prep-new/heldout.jsonl
```

The default seed is `20261103`, holdout size is 500, and maximum prompt length
is 16,000 characters. Oversized prompts are rejected, never truncated. CFP scans
all rows and retains all eligible rows by default. Future Code defaults to
50,000 generation prompts and a 250,000-English-row scan limit. `--count 0`
retains all eligible rows within the scan budget; `--scan-limit 0` scans the
entire source, which can be expensive for Future Code.

For an already downloaded CFP file, add
`--csv data/corpora/cfp/train.csv`. Its declared revision must match the download;
the script independently records the local file hash but cannot authenticate
an arbitrary local CSV's revision. Additional existing or held-out prompt files
can be excluded using repeatable `--exclude-prompts` arguments.

## Validate and smoke-test generation

Both prepared generation shards passed these CPU-only checks:

```bash
for shard in \
  data/runs/cfp-prep-20261103/prompts.jsonl \
  data/runs/future-code-prep-20261103/prompts.jsonl; do
  python -m scripts.generate_dataset \
    --prompts "$shard" \
    --teacher-revision 1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0 \
    --max-tokens 8192 --dry-run
done
```

Do not pass `heldout.jsonl` or directory-wide JSONL globs to generation or
training. The new held-out files are separate artifacts; the existing frozen
benchmark exclusion manifest was not changed. Normalized hashes ensure exact
deduplication, not detection of paraphrases or translations. Before any later
source preparation, pass both held-out files as extra exclusions as well.

After reviewing source terms and restarting the pinned teacher, smoke-test
each source separately before queuing bulk generation:

```bash
python -m scripts.generate_dataset \
  --prompts data/runs/cfp-prep-20261103/prompts.jsonl \
  --limit 200 --run-id cfp-smoke-20261103 \
  --base-url http://127.0.0.1:8000 --concurrency 64 \
  --teacher-revision 1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0 \
  --image-digest sha256:bc0445dac61accbf1c3b17fbb524a71eee0b1b32f55ba45952095e3be8991c3f \
  --max-tokens 8192 --temperature 0 --seed 0 --effort low --timeout 900
```
